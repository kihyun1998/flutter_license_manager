# example-app

## What it is
The demo Flutter app under `example/`: it loads licenses at startup, offers a registry-only view and a registry-plus-custom view, and shows each in a dialog with a list, a detail page and a copy button.

## Governing decisions
**None.**

## Design model
- Licenses are loaded once, before `runApp`, and injected (`main`, `loadAppLicenses`; commit `7a5e2b2`, #2, removed the old global). With custom licenses, the registry is read **twice** — once for each set. Kept simple on purpose because it is a demo (maintainer, 2026-10-24).
- `HomeScreen` centers its content and scrolls when the viewport is short, so it never overflows (commit `817f1fb`, #4; `example/test/home_screen_test.dart`).
- `LicenseDialog` switches between the list and a `LicenseDetailView` with an `AnimatedSwitcher` keyed on `packageName`.
- `licenseCountLabel` is the one place the count is worded (commit `f08d448`, #8); `buildCopyText` is the clipboard format (commit `6f0f456`, #6).
- `publish_to: 'none'`; it depends on the package by `path: ../` (`example/pubspec.yaml`). Only a Windows runner exists, generated by Flutter.
